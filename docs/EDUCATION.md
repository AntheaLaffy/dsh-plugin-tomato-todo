# 项目资料与应试教学

> 字段形状以 packages/core 的 TypeScript 实现为准：本文记录资料与应试教学的设计与流程，字段语义随核心实现更新。

项目把资料、学期进度、课程和训练证据关联起来，让助手能根据实际表现调整安排。侧栏「应试教育」聚合学生和教师视图；项目页的「项目资料与应试教学」保留资料库与完整教学记录，点击「让助手备课」进入助手。普通任务继续表达自由执行的事情，正式教学记录使用独立模型。

## 项目与目录

每个项目只使用自己授权的资料目录；没有共享资料库或默认回退。新建项目选择一个已存在的专用绝对目录，旧项目和备份恢复后的项目在项目页重新授权。授权记录保存在 `project-grants.json`（0600），不进入计划或备份；教学记录保存项目目录的绑定元数据，二者一致时才允许读取。启动时清理旧共享授权与旧索引文件，不改项目授权。授权目录不能是根目录、整个主目录、应用数据目录或符号链接，也不能与其他项目授权目录重叠。助手不能通过 MCP 授权目录。

项目页可从系统文件选择器一次选择多个外部文件，或选择整个目录递归上传。文件复制到当前项目的授权目录；目录上传保留所选目录及其子目录的相对层级，同名文件不会被覆盖。单文件可以直接放在项目根，按教材、真题、笔记等建子目录只是可选的整理方式，不影响资源类型和教学关联。上传成功后项目页刷新索引并批量登记；用户也能先把文件放进已授权目录，再在该项目页扫描和选择性登记。

学习助手拿到 DSH 会话附件的本地文件后，可用 DSH 自带文件工具将其复制到已授权的目标项目目录，再调用 `tomato_education` 的 `saveResource` 登记项目相对路径；当前没有单独的附件导入 Host 工具。它必须先确认目标项目及目录，不能把未指定项目的附件自动放进其他项目。跨项目整理同样先复制到目标授权目录，再更新资源所属项目和相对路径。上传或登记都不代表助手已经阅读原文。

资料目录整体搬家后，在项目页显式授权新目录；相对路径与资源 ID 保留，随后检查失效登记。旧共享目录中的项目改绑到其子目录时，仍存在的资源路径会去掉该子目录前缀并保留 ID。删除尚无学期记录的项目只删除应用索引，不删除外部文件；已有教学历史的项目须保留，停用应试模式停止未来教学事件。

## 资料查找、预览与清理

项目目录有两个层次：**磁盘索引**回答「此项目目录有什么」，**资源登记**回答「教学记录能引用什么」。项目页按需递归扫描当前授权目录，只记录文件名、相对路径、扩展名、大小与修改时刻，不读原文；跳过隐藏项、符号链接、`node_modules` 和 `.git`。索引按项目 ID 分开保存在 `dataDir/project-library-indexes/<sha256(projectId)>.json`，不进入计划、备份或 `education.resources`。换目录后旧索引失效，重新扫描即可。

项目页可按名称/相对路径搜索索引并按浏览类型或扩展名筛选；可以选择条目或整个目录登记为本项目资源，重复路径跳过。批量登记默认用中性的「参考」类型；资源的 `kind` 表示教学用途（考纲、课程、教材、真题、模拟题、参考、附件、答卷），不能仅凭扩展名判断，后续由用户或助手按用途整理。应试教育卡片的资料数量来自同一份 `education.resources` 按项目计数，默认状态快照省略明细也不再显示假零。资料正文由助手按教学需要读取；目前没有全文/OCR索引或独立阅读状态追踪。

图片、PDF和文本支持应用内预览，预览路径上限20 MiB；文本显示前20万字符。原件下载没有此大小限制；文件端点只允许当前项目索引中的安全相对路径，并支持 Range。作业题目来源、课程、答卷与订正附件可直接打开资源。

「检查失效登记」只读文件状态，不遍历内容；区分文件缺失和目录未授权、目录失联、权限错误等暂不可用状态，并列出教学引用。「修复路径」验证新文件后保留原 ID 及所有引用；整体搬家用重新授权。「清理缺失且无引用的登记」只移除登记，不删除磁盘文件；有教学引用的登记须保留。

## 应试教育面板

学生端只展示今天仍可执行的项目任务；已过期的定时任务、旧课程和历史任务不占用今日区域，已发布的作业只在作业队列出现一次（逾期作业仍可按真实时间补交）。未开考且安排日期已过的试卷标为缺考，不再占用待办或首页提示；考试当日可以自行选择开考时刻，开考后严格按固定时长计时，到点停笔。已开考的考试停笔后仍可自行选择交卷时间，不会因原计划时刻已过而作废，不能补考或超时继续作答。课程和缺考记录留在项目完整教学历史，教师端周记录仍可查阅。学生面板直接打开作业/测评详情提交或开考，也可把项目学情、作业与考试状态带入学习助手的可编辑请求，保留原有草稿，不自动发送。教师端对照当前学期教学周的里程碑、指定资料、计划/已排课时、实际参与、课程进度、发布/提交/批改及学情依据；教学周从学期起始日起算，末周按学期结束日裁剪。

两个视图读取同一份权威快照，不是独立账号或服务端权限角色。提交、批改与订正按当前快照建立索引，复用查询并随旧快照释放。待办状态从全部提交和批改推导，同秒多版本以最后保存版本为准；项目页展示完整课程和测评。助手入口预填备课/复盘请求，用户发送后按既有交互权限执行。

作业或试卷成功提交（含重交）后，弹层不自动关闭，仍提示「已提交」；提交区出现「去批改」按钮，点击后收起番茄面板、回到学习助手，把绑定本次提交和批改事件的请求追加进保留原草稿的输入框，供用户检查后发送（不自动发送）；未成功保存时保持提交表单。后台若已领取或完成同一事件，助手应先核对状态，避免重复批改。

## 启用与备课

应试项目必须有愿景、具体考试目标、考纲、真题、模拟题。资源带来源、版本与知识点，考纲需要明确年份和适用范围。先导入资料，再保存应试配置；缺少前置条件会被核心拒绝。

助手通过 `education` 工具维护正式记录，字段见随包技能 `exam-teaching/contract.md`。学期计划记录学情起点、证据、排期理由与每周知识点、资源及课时；修改递增版本并保留旧版本。已有课程也须与考纲及可查证经验核对，资源不足时联网补充；真实目标院校和考试规则由助手联网核实，不在安装包放入个人备考数据。

课程必须绑定本项目学期，固定45分钟；跨项目合计上午最多4节、下午最多4节，不与正式占用、其他课程或考试冲突。完整学习日按上午4节、下午2–4节安排，零散增排时不强制已经凑齐每天最低节数。到点状态变成已下课或缺课，单凭课程时钟不产生番茄或掌握记录。需要AI的已参与课程下课后生成作业事件。

「今日专注」是教学安排的统一执行入口。当前及未来日期的具体课程、已发布的作业各关联一条普通待办；只有周目标、还没有落到日期的里程碑不会被猜测拆分。`education.focusTasks` 保存 `taskId/sourceId/kind`，按来源去重；课程改期更新同一任务，轮询和重启不重复创建。任务列表、项目计数、提醒与番茄钟直接使用这条任务；周日程保留课程块，避免再画一份任务副本。教学来源拥有日期与内容，调整安排通过原课程或作业进行，普通计划导出排除教学待办，`replace` 保留它们。

在课程窗口内从今日专注开始实际专注会记录参与；本人勾选课程任务完成也记录参与与待补充的实际位置，不推定掌握。课程任务可以撤销完成，既有参与、作业和任务快照保留；实际计时和任务完成时的估算补足仍分别统计。课程任务只走课程作业事件，不再重复产生普通任务作业。作业可以在首页选择专注、点开题目并提交；只有最新完整提交才自动完成对应待办，标记未完成的提交保留待办，自动完成不会补造估算时长或番茄。考试在首页提供试卷、打印确认、开考与答题卡入口，继续使用正式考试时钟；「确认打印」改在工作台点按钮完成，仅考试类且未确认时出现，已确认后改为显示确认打印时间。

## 学情进度

项目页的「最新学情」按主题展示实际学到的位置、依据、状态、下一步、来源和确认状态；支持用户本人登记、确认助手整理的记录。每条进度记录保留历史，不以原地覆盖实现更正。`get_context`为助手提供带`asOf`的短摘要，`get_study_progress`按项目分页提供进度记录、任务快照、七日实际计时、作业/考试状态、提交、正式成绩、订正与复测关系。摘要由当前证据动态计算，不另存可失真的副本；待复核批改不发布正式分数。

任务勾选与实际番茄、知识掌握相互独立。启用应试模式项目的学习任务完成时，核心一次性保存任务内容快照并生成`taskHomework`教学事件；界面在新作业事件产生后直接进入学习助手，宿主领取作业事件时也唤回助手页面，普通任务与重开任务不会触发此跳转。课程作业在产生并领取事件后同样唤回助手；未连接或忙碌时仍等待执行。**普通休息和暂停的休息**允许领取作业事件、展示助手并保持休息计时；正在专注、锁机或正式考试时不强制切页，其他教学事件仍须等待计时完全空闲。跳转时输入框预填**可编辑但不会自动发送**的作业请求：绑定事件ID、项目和完成时的任务快照（课程则绑定课时、知识点、实际进度与指定资料），要求核对已学范围、项目资料和负荷，再按技能命题、复解与保存，避免后台正在处理时重复布置。已有输入草稿保留；后台领取事件引起的会话切换也不会冲掉它或重复追加同一事件。任务随后被移动或删除不影响来源追溯。助手按快照和最新学情决定是否能出题，作业以`taskId`关联原任务、`lessonId=null`。作业只能覆盖有依据的已学范围；不明部分先核实，不机械补齐通用分钟数。

## 作业、考试与复盘

正式作业、考试、学期计划、课程和批改不能由普通手动 Action 创建，只能交给助手。备份恢复用于恢复已有正式记录；发布过的题目、答案和评分标准不能用导入/补丁覆写。普通任务不被自动解释成正式作业。

每份发布包包含题目、来源、知识点、估时、标准答案、可接受替代解法、分步评分点与独立复核记录。基础练习覆盖已学知识，拓展题明确标记；全真模拟允许覆盖完整考纲。规则校验不能证明AI答案正确，实际复解与复核由助手执行，用户可要求复核。

命题同时读取随包的 [exam-authoring](../plugin/skills/exam-authoring/SKILL.md)：真题作为设问、思维要求、条件严谨性与评分尺度的质量基准；教材、讲义、笔记、错题、外刊、音视频、专题与补充材料分别按其贡献取材，不把命题收窄成真题改写。先留存蓝图和资料贡献，再写题、评分并完成不看拟定答案的复解与适用核验；未解决的来源、答案或规则争议保留为草稿。题目细部来源与验证过程保存到授权项目目录，`reviewEvidence`记录结论和位置。随技能的Python检查器只核对结构、数量、总分、来源ID与时间窗口；通过不证明资料已读、答案正确或达到真题质量。技能约束不替代核心校验，也不构成模型绝不会出错的保证。

180分钟是全科作业供给的通用聚合基线，不是每科配额或必须补足的最低量；用户明确要求的时间表、固定课程和当日负荷优先，课程量与作业量分开核算，负荷较重时减少作业而不追补差额。19:00–22:00是默认晚间作业窗口，实际作息以用户设置为准；到收工时间提交已完成部分，未完成内容如实保留。复盘按用户作息与固定课程安排，不使用与现实冲突的统一默认钟点。

周五至周末为每个启用项目的当前学期生成周考准备事件；助手分配周末两天的考试窗口，避免跨项目各排一整天。阶段测试覆盖已学，全真模拟使用目标考试完整规则。试卷和答题卡导出为可打印的独立HTML，不含标准答案；逐题记录本地24小时制HH:MM完成时刻；上传带时刻的答题卡即可，提交表单中的逐题时刻为折叠的可选补录项，无需重复抄写。批改事件中的助手先读取答题卡，只将能辨认且尚未记录的时刻写入提交记录；无法读取图片/PDF或识别不清的题目保持缺失并说明原因，不猜测或覆盖用户输入。补录必须发生在正式批改前，提交的答案与附件仍不可改写；表单文本输入不依赖系统地区设置导致的AM/PM控件。确认打印后可在安排的考试日期当天任意时刻开考，`startsAt/endsAt` 只确定考试日与固定时长，不把计划开考钟点当作硬截止。实际开考后从 `startedAt` 起倒计时 `endsAt-startsAt` 秒，跨午夜也按该时长自动停笔；应用关闭时在下次 tick 按真实截止恢复，不补给额外答题时间。未开考且日期已过视为缺考。已开考并停笔的答卷可自行决定交卷时间，正式考试答卷必须含项目资源附件；记录真实提交时间，不将晚于原计划窗口的交卷误判成逾期作答。照片与自报时刻不能证明线下考场行为。

提交不可覆盖，重交创建新版本。批改逐评分点记录得分和答卷证据，禁止超分、重复评分、增加临时评分点或漏掉正式评分点。识别不清设置needsReview，不作确定评分；合理新解法请求复核。复核使用新批改ID保留旧记录。错因分析记录依据、纠正动作、下次检查信号与复测日期，未证实的原因保留待确认。订正按原批改和题目提交，独立教学事件检查后保存接受/继续订正及反馈；即使订正通过，仍须通过关联原批改的独立复测试卷验证掌握。

## 持久化与执行

备份v5新增可选 `education` 对象（旧备份缺省为空）：projects/resources/semesters/semesterHistory/lessons/assessments/submissions/grades/reviews/events/completedTasks/progress/corrections。计划v7继续只交换普通计划，不承载教学历史，不移除本地教学记录。目录资源与本机授权不打包进JSON备份，需单独备份外部目录；换机恢复后重新选择目录授权。

核心tick负责到点状态和homework/grade/review/weeklyExam事件。事件以固定来源ID去重，状态pending/running/done，和普通数据一起原子持久化；每日复盘等错过的状态在重新运行后补齐。已连接且空闲时，宿主领取待处理事件，沿用现有 scheduled 会话语义（现由 DSH 对话中的助手执行），执行时可使用正式教学工具，不另加模型调度层、时限或循环重试。助手保存实际产物后finishEvent；用户停止、供应商错误或关机留下未完成事件，由助手在用户要求继续时调用retryEvent恢复处理。停用应试模式不再领取该项目事件，已开始请求需用户主动停止。

应用关闭时不运行模型，模型不可用时等待；已开考的考试在下次 tick 按实际开考时间和固定时长恢复停笔状态，关机期间不会延长考试。当前无离线OCR引擎，PDF/照片的识别取决于沙箱工具和所连接模型的视觉能力。

验证：`pnpm core:test`（含 `education.test.ts`）、`pnpm runtime:test`、`pnpm test:tools` 与 `pnpm check:client`；测试只用临时目录与假 DOM，不动真实学习资料、不花模型额度、不启用当前桌面保护。

## 本次任务资料与完成确认

AI 布置课程时应填写 `Lesson.resourceIds`，布置作业或考试时应填写 `Assessment.resourceIds`（本场试卷、空白答题卡和本次参考资料）。引用必须是本项目已登记的资源，不重复；逐题命题依据继续写 `Question.sourceIds`。编辑栏优先展示本次明确引用的资料；没有指定本次 resourceIds 时回退到项目资料。答案评分独立保存，不作为学生参考资料附上。

课程、作业和各类考试均生成关联待办，任务需要用户明确确认完成。参与课程、番茄结束、考试停笔、答卷提交、批改与完成任务各自记录，互不替代；作业和考试只有完整提交后才允许确认完成，提交不会自动勾选。编辑栏提供确认任务完成按钮。
